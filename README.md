# An AI-Driven Teacher-Assisted Learning System - Backend

## 📌 Project Overview

This repository contains the backend and AI-related components of the **AI-Driven Teacher-Assisted Learning System** developed to support Grade 1 students through personalized and interactive learning.

The backend acts as the core processing layer of the system. It manages application data and provides the services required to support personalized learning, student performance analysis, learning activities, assessments, and AI-assisted educational features.

As part of the research component, the system also supports the **collection, preprocessing, training, evaluation, and deployment of machine learning/deep learning models** that can be integrated into the educational platform.

---

## 🎯 Research Objective

The overall research project focuses on:

**An AI-Driven Teacher-Assisted Learning System to Enhance Motor Skills and Creativity Among Grade 1 Students through Personalized Interactive Learning.**

The system aims to help teachers understand individual student learning needs and provide appropriate personalized learning activities based on student performance and learning progress.
